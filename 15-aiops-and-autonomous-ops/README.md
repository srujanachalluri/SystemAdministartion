## Running the reps

```bash
python code/mcp_client_demo.py                  # Reps 1-2

echo '{"tool_input":{"command":"kubectl delete pvc data-var"}}' \
  | ./code/approval_gate.sh; echo "exit=$?"     # Rep 3 -> exit 2
echo '{"tool_input":{"command":"du -x -d1 /var"}}' \
  | ./code/approval_gate.sh; echo "exit=$?"     # Rep 3 -> exit 0

nc -l 9999 &                                    # Rep 8 (localhost only)
python code/exfil_demo.py --mode vulnerable
python code/exfil_demo.py --mode fixed

python code/log_summarize.py code/hostile_incident.log   # Rep 9

python code/self_heal.py                        # Rep 10 - gated, node-7
python code/self_heal.py --ungated              # Rep 11 - ungated, node-4
```

Nothing destructive runs for real. Remediation effects are simulated against
`code/sim_state.json`, which stands in for `node_filesystem_avail_bytes`.
